കൃത്യമായ നമസ്കാര സമയം ലഭിക്കാൻ Location Permission അനുവദിക്കുക
നിങ്ങളുടെ ഇപ്പോഴത്തെ സ്ഥലമനുസരിച്ചാണ് Prayer Times & Qibla കണക്കാക്കുന്നത്. Location Permission അനുവദിച്ചാൽ നിങ്ങളുടെ നിലവിലെ location ഉപയോഗിച്ച് കൂടുതൽ കൃത്യമായ സമയം ലഭിക്കും.
Permission നേരത്തെ Block ചെയ്തിട്ടുണ്ടെങ്കിൽ, Browser / App Settings → Site Permissions → Location → Allow ചെയ്യേണ്ടി വരാം.

നിങ്ങളുടെ location ലഭിച്ചതിന് ശേഷം Qibla direction കാണിക്കും.
📌 Prayer Times നിങ്ങളുടെ current location അനുസരിച്ചാണ് കണക്കാക്കുന്നത്.
📌 Location permission അനുവദിക്കാത്ത പക്ഷം മുമ്പ് save ചെയ്ത location ലഭ്യമാണെങ്കിൽ അത് ഉപയോഗിക്കും.
📌 Saved location ഇല്ലെങ്കിൽ Kerala (Palakkad) fallback ഉപയോഗിക്കും.
📌 നിങ്ങളുടെ exact address ഈ app display ചെയ്യുകയോ save ചെയ്യുകയോ ചെയ്യുന്നില്ല. Prayer calculation-ന് ആവശ്യമായ location coordinates മാത്രമാണ് ഉപയോഗിക്കുന്നത്.
